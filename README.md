# E-Commerce Customer Segmentation Using RFM, K-Means and DBSCAN

## Project Overview

This project focuses on segmenting e-commerce customers based on their purchasing behaviour using **Unsupervised Machine Learning** techniques.

The project uses the Online Retail II dataset to perform RFM (Recency, Frequency, Monetary) analysis and applies two clustering algorithms, K-Means and DBSCAN, to identify meaningful customer segments.

PCA (Principal Component Analysis) and t-SNE (t-distributed Stochastic Neighbor Embedding) are used for dimensionality reduction and visualization.

The final objective is to identify valuable customer groups and develop actionable marketing personas that can help businesses improve customer retention, personalize marketing campaigns, and optimize business strategies.

## Objectives

- Analyze customer purchasing behaviour using transactional data.
- Perform RFM (Recency, Frequency, Monetary) analysis.
- Clean and preprocess the raw transaction dataset.
- Apply feature scaling and logarithmic transformation.
- Implement K-Means clustering.
- Implement DBSCAN clustering.
- Reduce dimensionality using PCA.
- Visualize customer segments using t-SNE.
- Evaluate and compare clustering algorithms.
- Develop meaningful customer personas.
- Suggest targeted marketing strategies for each customer segment.

## Dataset

**Dataset Name:** Online Retail II

**Source:** UCI Machine Learning Repository

**Dataset Link:** https://archive.ics.uci.edu/dataset/502/online+retail+ii

The dataset contains approximately 1.07 million transactions from a UK-based online retailer between December 2009 and December 2011.

### Dataset Attributes

| Attribute | Description |
|---|---|
| InvoiceNo | Unique transaction or invoice number |
| StockCode | Unique product identifier |
| Description | Product description |
| Quantity | Number of products purchased |
| InvoiceDate | Date and time of transaction |
| UnitPrice | Price per product |
| CustomerID | Unique customer identifier |
| Country | Customer's country |

## RFM Analysis

RFM analysis is used to understand customer purchasing behaviour through three important metrics.

### 1. Recency (R)
Measures the number of days since the customer's most recent purchase.

Lower recency indicates a more recently active customer.

### 2. Frequency (F)
Measures the number of distinct invoices generated by a customer.

Higher frequency indicates more frequent purchases.

### 3. Monetary (M)
Measures the total amount spent by a customer.

Monetary Value = Quantity × UnitPrice

A higher monetary value indicates greater customer spending.

## Machine Learning Algorithms

### K-Means Clustering

K-Means is an unsupervised machine learning algorithm that divides customers into a predefined number of clusters based on similarity in their RFM features.

The optimal number of clusters is investigated using the Elbow Method and Silhouette Score.

### DBSCAN Clustering

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) groups customers based on the density of nearby observations.

It does not require a predefined number of clusters and can identify noise points and unusual customer behaviour.

## Dimensionality Reduction

### PCA (Principal Component Analysis)

PCA is used to reduce the dimensions of the RFM feature space while retaining as much information, measured by variance, as possible.

It is also used to visualize customer distributions in two dimensions.

### t-SNE

t-SNE is a nonlinear dimensionality reduction technique used to visualize high-dimensional customer data in a two-dimensional space.

It helps explore local structures and patterns among customer segments.

## Model Evaluation

The clustering algorithms are evaluated using:

- Silhouette Score
- Davies-Bouldin Index
- Number of identified clusters
- Cluster size distribution
- DBSCAN noise percentage

The results are compared to understand the quality and usefulness of the generated customer segments.

Note: DBSCAN evaluation metrics are calculated on non-noise customers where appropriate.

## Customer Segmentation and Marketing Personas

The identified customer clusters are interpreted using their RFM characteristics.

The project considers the following marketing personas:

| Customer Persona | Marketing Strategy |
|---|---|
| Champions | VIP rewards and exclusive offers |
| Loyal Customers | Membership and referral programs |
| Recent / New Customers | Welcome offers and second-purchase incentives |
| At-Risk High-Value Customers | Personalized win-back campaigns |
| Big Spenders / Occasional Buyers | Premium recommendations and product bundles |
| Hibernating Customers | Re-engagement campaigns and discounts |
| Regular / Developing Customers | Personalized product recommendations |

The personas are assigned using rule-based interpretations of the cluster-level RFM profiles.

## Project Limitations

- Customer records with missing CustomerID values cannot be included in customer-level RFM analysis.
- Cancelled invoices and non-positive quantities are excluded from the main purchasing analysis.
- RFM captures purchasing behaviour but does not include all customer preferences or demographic information.
- DBSCAN performance depends on its density parameters.
- t-SNE is primarily a visualization technique and should not be treated as a clustering evaluation method.
- Historical customer activity does not necessarily represent present-day purchasing behaviour.
