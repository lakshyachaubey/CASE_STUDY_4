## 1. Abstract

Customer segmentation is an important technique used in e-commerce businesses to understand customer purchasing behaviour and develop personalized marketing strategies.

This project applies unsupervised machine learning algorithms to segment customers using the Online Retail II transaction dataset.

Recency, Frequency, and Monetary (RFM) analysis is used to extract customer purchasing characteristics. K-Means and DBSCAN clustering algorithms are applied to identify groups of customers with similar purchasing patterns.

Principal Component Analysis (PCA) is used for dimensionality reduction and t-SNE is used to visualize the customer segments.

The resulting clusters are interpreted to develop marketing personas and actionable recommendations for improving customer engagement and retention.

## 2. Problem Statement

E-commerce companies collect large amounts of transaction data, but identifying different customer behaviours from this data can be challenging.

Treating all customers equally may result in ineffective marketing campaigns and missed opportunities.

This project aims to identify meaningful customer segments using RFM analysis and unsupervised machine learning techniques.

## 7. RFM Feature Engineering

RFM represents three important characteristics of customer purchasing behaviour.

### Recency

Measures the number of days since the customer's last purchase.

Recency = Reference Date − Last Purchase Date

### Frequency

Measures the number of distinct invoices generated by the customer.

### Monetary

Measures the total amount spent by each customer.

Monetary = Sum of (Quantity × UnitPrice)

The reference date is set to one day after the latest valid transaction.

## 8. Feature Transformation and Scaling

## 12. Model Evaluation

The models are evaluated using:

### Silhouette Score

Measures how similar a customer is to its own cluster compared with other clusters.

Higher values generally indicate better separation.

### Davies-Bouldin Index

Measures similarity between clusters.

Lower values generally indicate better-defined clusters.

### Noise Percentage

Measures the proportion of customers classified as noise by DBSCAN.

DBSCAN's silhouette and Davies-Bouldin metrics are calculated on non-noise observations.

## 17. Limitations

- Missing CustomerID values cannot be included in customer-level segmentation.
- Historical transaction data may not represent current customer behaviour.
- RFM does not include demographic information or all customer preferences.
- DBSCAN is sensitive to its density parameters.
- t-SNE is mainly used for visualization and does not establish clustering quality.
- Returns and cancellations are excluded from the main purchasing analysis.
